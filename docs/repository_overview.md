
# Memory-Driven Option Pricing: A Multi-Factor Affine Stochastic Volatility Framework for Option Valuation and Mispricing Detection

## Executive Summary

This repository presents a research-oriented framework for option pricing based on a multi-factor memory-driven stochastic volatility model.

The framework extends classical affine volatility models by introducing multiple interacting memory components operating across different time horizons. These memory factors allow the model to capture volatility persistence, clustering effects, skew structures, smile dynamics, and long-memory behavior observed in financial markets.

Unlike traditional single-factor stochastic volatility models, the proposed framework decomposes volatility into several memory horizons, allowing separate representation of short-term, medium-term, and long-term market effects.

The resulting system preserves affine tractability, admits an exponential-affine characteristic function representation, and supports efficient Fourier-based valuation techniques.

The framework establishes a mathematical pipeline connecting volatility forecasting, option valuation, calibration, and systematic mispricing detection.

## Research Motivation

Modern option markets exhibit several stylized facts that are difficult to explain under classical models.

These include:

* Volatility clustering
* Volatility persistence
* Long-memory effects
* Implied volatility smiles
* Implied volatility skews
* Heavy tails
* Leverage effects
* Multi-scale volatility behavior

Traditional Black-Scholes models assume constant volatility and therefore fail to reproduce observed option surfaces.

More advanced stochastic volatility models introduce latent variance dynamics but often rely on a single variance factor.

Empirical evidence suggests that volatility operates simultaneously across multiple time scales.

Market shocks generate immediate effects, intermediate persistence, and long-run structural impacts.

A single variance factor cannot adequately represent this hierarchy.

The objective of this research is therefore to construct a mathematically tractable stochastic volatility framework capable of representing multiple memory horizons while preserving pricing efficiency.

## Model Structure

The model consists of three interacting components:

1. Asset Price Process
2. Variance Process
3. Memory Factors

The asset price evolves under the risk-neutral measure.

The variance process is generated by multiple memory components.

Each memory component captures volatility persistence operating at a specific time scale.

### Memory-Based Variance Decomposition

The instantaneous variance is represented as

$$
v_t = \omega + \sum_{i=1}^{m} \alpha_i U_t^{(i)}
$$

where

* $\omega$ is the baseline variance level,
* $\alpha_i$ denotes the loading coefficient,
* $U_t^{(i)}$ denotes memory factor $i$.

The variance process therefore becomes a superposition of multiple memory horizons.

Conceptually,


Variance
=
Baseline
+
Short-Term Memory
+
Medium-Term Memory
+
Long-Term Memory


rather than a single latent volatility factor.

### Memory Dynamics

Each memory component evolves according to

$$
dU_t^{(i)} = \left( -\lambda_i U_t^{(i)} + v_t \right) dt + \epsilon_i \sqrt{v_t} \, dZ_t^{(i)}
$$

The parameter

$$
\lambda_i
$$

controls memory decay.

Large values correspond to rapidly decaying short-term memory.

Small values correspond to persistent long-term memory.

The parameter

$$
\epsilon_i
$$

controls volatility-of-volatility effects associated with factor $i$.

### Multi-Horizon Interpretation

A representative specification may be

$$
(\lambda_1,\lambda_2,\lambda_3) = (10,2,0.2)
$$

corresponding approximately to


Factor 1 → Daily Memory
Factor 2 → Weekly Memory
Factor 3 → Monthly Memory


The framework therefore separates volatility persistence across multiple horizons.

## Affine Process Foundation

The model belongs to the family of affine stochastic processes.

Affine processes are particularly important because they admit tractable characteristic function representations.

The state vector is

$$
Y_t = \left( X_t, U_t^{(1)}, U_t^{(2)}, \ldots, U_t^{(m)} \right)
$$

Both drift and covariance depend linearly on the state variables.

Consequently the model preserves affine structure.

This property allows efficient valuation methods unavailable in many non-affine systems.

## Characteristic Function Representation

The conditional characteristic function admits the form

$$
\phi(u,T) = \exp\left( A(T,u) + B(T,u)^\top U_0 + i u X_0 \right)
$$

The entire future distribution of asset prices is encoded within the coefficient functions

$$
A(T,u)
$$

and

$$
B(T,u).
$$

Once these functions are known, option valuation becomes tractable.

## Riccati Equation Framework

The coefficient functions satisfy a coupled system of Riccati differential equations.

The Riccati system governs:

* Volatility persistence
* Correlation effects
* Volatility-of-volatility dynamics
* Tail behavior
* Smile curvature
* Skew generation

Solving this system completely determines the characteristic function.

The characteristic function then determines all option prices.

## Option Pricing Methodology

The framework prices European options through Fourier inversion.

The pricing workflow is

State Variables
        ↓
Riccati System
        ↓
Characteristic Function
        ↓
Fourier Transform
        ↓

This avoids direct simulation and enables computational efficiency.

## FFT Acceleration

Direct evaluation of large option surfaces can be computationally expensive.

The framework therefore supports Fast Fourier Transform pricing.

Complexity is reduced from

$$
O(N^2)
$$

to

$$
O(N \log N)
$$

allowing efficient calibration against large volatility surfaces.

## Calibration Framework

Model parameters are estimated using market option data.

The calibration procedure minimizes

$$
L(\theta) = \sum_{i=1}^{N} w_i \left( \sigma_i^{\rm model} - \sigma_i^{\rm market} \right)^2
$$

The resulting parameter vector generates the volatility surface that best matches observed market prices.

## Sensitivity Analysis

Parameter sensitivities are computed analytically.

The Jacobian matrix

$$
J_{ij} = \frac{\partial r_i}{\partial \theta_j}
$$

measures the sensitivity of model errors with respect to model parameters.

Analytical derivatives significantly accelerate calibration procedures.

## Optimization Framework

The repository implements two major optimization methodologies:

* **Gauss-Newton** — Provides rapid convergence near optimal solutions.
* **Levenberg-Marquardt** — Introduces regularization to stabilize optimization when parameter sensitivity matrices become ill-conditioned.

These methods allow robust parameter estimation.

## Mispricing Detection Engine

The framework is designed not only to price options but also to identify valuation discrepancies.

Given

$$
C_{\rm model}
$$

and

$$
C_{\rm market}
$$

define

$$
\Delta C = C_{\rm market} - C_{\rm model}
$$

A normalized signal is constructed as

$$
Z = \frac{C_{\rm market} - C_{\rm model}}{\sigma_\Delta}
$$

Large absolute values indicate potential mispricing opportunities.
